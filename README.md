# Stream Multichat

O chat ao vivo dos seus canais da **Twitch** e da **Kick** juntos numa janela só, para Windows.

Este repositório guarda só os **instaladores** e os arquivos que o app usa para se **atualizar sozinho**. O código-fonte não fica aqui.

## Baixar

Vá em [Releases](../../releases) e baixe o `stream-multichat-<versão>-setup.exe` da versão mais recente.

- O app está em **beta**: todas as versões por enquanto são pré-lançamentos.
- O instalador ainda não tem assinatura digital, então o Windows pode mostrar o aviso do SmartScreen na primeira instalação ("Mais informações" → "Executar assim mesmo").
- Para conferir o download, compare o SHA-256 do arquivo com o `SHA256SUMS.txt` do mesmo release.

## Atualizações

Depois de instalado, o app procura versões novas neste repositório, baixa em segundo plano e mostra **"Reiniciar para atualizar"** na barra de baixo. Nada é instalado sem o seu clique, e cada instalador é conferido por uma assinatura antes de ser instalado.
